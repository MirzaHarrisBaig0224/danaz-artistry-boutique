# Cozy Craft Studio

Create a cute, cozy, feminine and professional one-page e-commerce website for a handmade accessories brand called **“Artistry by Danaz.”**

The brand sells handmade and aesthetic products such as **crochet keychains, bracelets, handmade jewelry, charms, cute accessories and giftable items**.

The website should feel like a **small Pinterest-inspired handmade boutique** — warm, adorable, artistic and premium, while still being clean and modern. It should make visitors want to browse products, discover cute pieces and place an order.

## BRAND FEEL

The visual identity should communicate:

* Handmade

* Cute

* Cozy

* Feminine

* Creative

* Personal

* Giftable

* Slightly luxurious

Use a soft color palette built around:

* Blush pink

* Dusty rose

* Cream / ivory

* Warm beige

* Soft brown

* Champagne gold as a subtle accent

Use elegant serif typography for headings combined with a cute handwritten/script font for decorative text.

The **ND monogram** should be incorporated into the branding as a small elegant logo/icon.

---

## NAVIGATION

Create a clean sticky navigation bar:

**ND Logo | Home | Shop | About | Gallery | Contact**

Add a cute **“Shop Now”** button on the right.

## ANIMATION STYLE

Make the website feel **cute and alive**, but don't overdo the animations.

Use:

* Smooth scrolling

* Gentle fade-up section reveals

* Soft floating hearts/stars

* Subtle product-card hover animations

* Image zoom on hover

* Smooth category filtering

* Cute add-to-cart animation

* Animated cart counter

* Smooth testimonial carousel

* Soft page-load animation

* Subtle floating decorative elements

The animations should feel **playful, cozy and handmade**, not flashy.

---

## IMPORTANT DESIGN DIRECTION

Do NOT make this look like a generic Shopify store or corporate e-commerce website.

Think:

**Pinterest + Etsy + cute Instagram boutique + handmade craft studio.**

The website should feel like someone discovered a beautiful little handmade business on Instagram and decided to explore the entire collection.

Use lots of whitespace, beautiful product photography, soft backgrounds, rounded cards, tiny decorative details and elegant typography.

The final result should make the visitor think:

**“Everything here is so cute — I want to buy something.”**
